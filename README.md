## Задание №11. Поиск информации в документах (через LibreOffice)

**Суть задания:** В каталоге с множеством вложенных папок и файлов разных форматов (`.txt`, `.doc`, `.docx`, `.odt`, `.rtf`, `.pdf`, `.html`) нужно найти конкретное слово, фразу или персонажа и выписать ответ (название файла, автора, имя героя и т. д.).

Так как стандартный поиск Astra Linux часто не индексирует текст внутри офисных форматов (`.doc`, `.docx`, `.odt`), самый надёжный способ -- использовать **LibreOffice Writer** и инструменты конвертации.

### Способ 1. Графический (Поиск файлов + LibreOffice Writer)
Этот способ идеален, если файлов нужного формата немного (например, в условии сказано: *«в одном из произведений, представленных в формате `.odt` или `.docx`»*).

1. Откройте корневую папку задания в **Менеджере файлов Fly**.
2. Нажмите **`Ctrl + F`** (поиск).
3. В поле **«Имя файла»** отфильтруйте только текстовые документы, например: `*.doc*` или `*.odt` (убедитесь, что включён поиск во вложенных папках и отключён учёт регистра).
4. Выделите найденные файлы, нажмите **`Enter`** (или правая кнопка мыши $\rightarrow$ **Открыть в LibreOffice Writer**).
5. В открывшемся окне документа нажмите **`Ctrl + F`** (панель «Найти» внизу окна) или **`Ctrl + H`** («Найти и заменить»).
6. Введите искомое слово **без окончания** (например, вместо «Евгений» пишите `Евгени`, чтобы учесть все падежи) и нажимайте **`Enter`** для перехода по совпадениям.

> **Важно:** Если нужно узнать **название файла**, в котором нашёлся текст, посмотрите на самую верхнюю строку окна LibreOffice Writer (заголовок окна) -- там всегда написано имя открытого документа.

### Способ 2. Консольный (Конвертация через LibreOffice + `grep`)
Если файлов десятки или сотни и открывать каждый вручную долго, можно прямо в терминале заставить LibreOffice быстро перевести все документы в чистый текст (`.txt`) во временную папку и мгновенно найти нужное слово командой `grep`.

1. Откройте папку с заданием и запустите в ней терминал (клавиша **`F4`** или ПКМ $\rightarrow$ **«Открыть терминал»**).
2. Выполните следующую цепочку команд (можно скопировать и вставить целиком):

```bash
# 1. Создаём временную папку для текстовых копий
mkdir /tmp/oge_text

# 2. Находим все документы (.doc, .docx, .odt, .rtf) и конвертируем их в .txt через LibreOffice
find . -type f  -iname "*.doc" -o -iname "*.docx" -o -iname "*.odt" -o -iname "*.rtf"  -exec libreoffice --headless --convert-to txt:Text --outdir /tmp/oge_text {} +

# 3. Ищем нужное слово во всех сконвертированных файлах
grep -rni "искомое_слово" /tmp/oge_text
```

**Как читать результат в терминале:**
Терминал выведет строчку вида:
`/tmp/oge_text/Преступление_и_наказание.txt:142: ...текст с искомым словом...`
Здесь сразу видно **имя файла** (`Преступление_и_наказание`), номер строки и сам контекст!

*(Примечание: чтобы это сработало, все окна LibreOffice перед запуском команды должны быть закрыты, иначе режим `--headless` не запустится).*

## Задание №12. Подсчёт количества файлов и их размера

**Суть задания:** Определить, сколько файлов с определённым расширением (например, `.txt` или `.doc`) и/или заданным размером находится в каталоге и всех его подкаталогах.

### Способ 1. Графический (Файловый менеджер Fly)
1. Откройте корневую папку задания и нажмите **`Ctrl + F`**.
2. В поле **«Имя файла»** (маска поиска) укажите шаблон:
   * Все файлы с расширением `.txt`: `*.txt`
   * Все файлы формата Word (`.doc` и `.docx` сразу): `*.doc*`
   * Любые файлы (если нужно посчитать только по размеру): `*`
3. **Уберите учёт регистра!** В Linux `file.TXT` и `file.txt` -- это разные расширения. В параметрах поиска Fly обязательно снимите галочку **«Учитывать регистр»**.
4. **Фильтрация по размеру (если требуется в условии):**
   * Перейдите на вкладку **«Дополнительно»** (или *Свойства*) в окне поиска.
   * Выберите условие для размера (например, *Больше чем 100 КБ*).
   * *Внимание на единицы измерения:* В ОГЭ **1 Кбайт = 1024 байта**. Некоторые программы считают 1 КБ = 1000 байт. Если есть файлы с размером на границе (например, 101 КБ), проверьте их точный размер в байтах через **ПКМ $\rightarrow$ Свойства**.
5. Посмотрите в **строку состояния** в самом низу окна: `Найдено объектов: X`. Убедитесь, что в список не попали папки (иногда папка может называться `backup.txt`).

### Способ 2. Консольный (Терминал + `find` и `wc`)
Команда `find` в терминале решает любую 12-ю задачу без ошибок с округлением и случайным подсчётом папок. Откройте терминал в нужной папке клавишей **`F4`**.

#### 1. Подсчёт файлов по расширению
```bash
find . -type f -iname "*.txt" | wc -l
```
* `.` -- искать в текущей папке и во всех вложенных.
* `-type f` -- искать **только файлы** (исключает папки).
* `-iname "*.txt"` -- маска имени с **игнорированием регистра** (`i` = ignore case, найдёт и `.txt`, и `.TXT`).
* `| wc -l` -- передать список найденных файлов счётчику строк, который выведет готовое число.

**Если нужно посчитать сразу два расширения (например, `.doc` и `.docx`, или `.jpg` и `.png`):**
```bash
find . -type f  -iname "*.doc" -o -iname "*.docx"  | wc -l
```
*(Флаг `-o` означает логическое «ИЛИ»).*

#### 2. Подсчёт файлов с учётом размера
Для фильтрации по размеру добавляется флаг `-size`. В Linux для ОГЭ лучше всегда переводить размер в **байты** (суффикс `c`):
$$\text{Байты} = \text{Кбайты} \times 1024$$

* **Строго больше (`+`)**: Найти количество `.txt` файлов размером **более 100 Кбайт** ($100 \times 1024 = 102400$ байт):
  ```bash
  find . -type f -iname "*.txt" -size +102400c | wc -l
  ```

* **Строго меньше (`-`)**: Найти количество файлов размером **менее 50 Кбайт** ($50 \times 1024 = 51200$ байт):
  ```bash
  find . -type f -size -51200c | wc -l
  ```

* **Не менее / не более ($\ge$ или $\le$)**: В `find` нет знаков `>=` и `<=`, поэтому просто сдвигаем границу на **1 байт**:
  * *Не менее 10 Кбайт ($\ge 10240$ байт)* $\rightarrow$ пишем строго больше $10239$ байт:
    ```bash
    find . -type f -size +10239c | wc -l
    ```
  * *Не более 10 Кбайт ($\le 10240$ байт)* $\rightarrow$ пишем строго меньше $10241$ байт:
    ```bash
    find . -type f -size -10241c | wc -l
    ```
