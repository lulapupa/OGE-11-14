# Шпаргалка для ОГЭ: `grep` и `find` (только нужное)

* **`grep`** ищет **текст внутри** файлов (для №11).
* **`find`** ищет **сами файлы** по имени, типу и размеру (для №12).

---

## Утилита `grep` -- поиск текста внутри файлов (Задание №11)

Базовый синтаксис:
```bash
grep [флаги] "что_ищем" где_ищем
```

### Главная формула для ОГЭ
```bash
grep -rni "искомое_слово" .
```
*(Точка `.` в конце означает «искать в текущей папке и во всех вложенных»).*

### Обязательные флаги

| Флаг | Расшифровка | Зачем нужен на ОГЭ |
| :--- | :--- | :--- |
| **`-r`** | *recursive* (рекурсивно) | Заходит во все подпапки внутри каталога. Без него `grep` выдаст ошибку при попытке поиска в папке. |
| **`-i`** | *ignore case* (игнорировать регистр) | Найдёт слово, даже если оно написано ЗАГЛАВНЫМИ буквами, с большой или с маленькой (`Москва`, `МОСКВА`, `москва`). |
| **`-n`** | *line number* (номер строки) | Выведет номер строки, в которой нашлось слово -- удобно, если потом нужно открыть файл и посмотреть соседние абзацы. |
| **`-w`** | *word* (слово целиком) | Ищет точное совпадение слова. **Осторожно:** не ставьте этот флаг, если ищете слово по корню без окончания (например, `Онегин` вместо `Онегина`). |
| **`-l`** | *files with matches* (только имена файлов) | Выведет **только названия файлов**, где есть совпадение, без самого текста. Спасает, если слово встречается 500 раз и забивает весь экран. |

### Полезные приёмы с `grep`
1. **Ищем слово с разными окончаниями (падежами):**
   Убираем окончание и не ставим флаг `-w`:
   ```bash
   grep -rni "Дубровск" .
   ```
   *(Найдёт «Дубровский», «Дубровского», «Дубровскому»).*

2. **Ищем фразу из нескольких слов:**
   Обязательно берём её в кавычки:
   ```bash
   grep -rni "капитанская дочка" .
   ```

3. **Ищем одно из двух слов (логическое «ИЛИ»):**
   Используем флаг `-E` и вертикальную черту `|`:
   ```bash
   grep -rniE "Пушкин|Лермонтов" .
   ```

4. **Ищем только в файлах конкретного расширения (например, только в `.txt` или `.html`):**
   ```bash
   grep -rni --include="*.txt" "слово" .
   ```

## Утилита `find` -- поиск и подсчёт файлов (Задание №12)

Базовый синтаксис:
```bash
find где_ищем [условия_поиска] | wc -l
```
Конструкция **`| wc -l`** в конце берёт список найденных файлов и считает количество строк (то есть сразу выдаёт готовый ответ для ОГЭ -- целое число).

### Главная формула для ОГЭ
```bash
find . -type f -iname "*.txt" | wc -l
```

### Обязательные флаги

#### 1. Тип объекта (`-type`)
* **`-type f`** -- искать **только файлы**. *Ставить обязательно!* В задачах ОГЭ бывают папки-ловушки с названиями вроде `archive.txt`. Без этого флага `find` посчитает и папку тоже.

#### 2. Имя и расширение файла (`-iname`)
* **`-iname "*.расширение"`** -- ищет файлы по маске, **игнорируя регистр** букв (`i` = ignore case). Найдёт и `doc.txt`, и `DOC.TXT`, и `Doc.Txt`.
  * Все текстовые: `-iname "*.txt"`
  * Все картинки JPEG: `-iname "*.jpg"`
  * Любые файлы (если нужно считать только по размеру): флаг `-iname` просто не пишем.

#### 3. Несколько расширений сразу (`-o` -- логическое «ИЛИ»)
Если нужно посчитать, например, все веб-страницы (`.htm` и `.html`) или все документы Word (`.doc` и `.docx`), условия объединяют через `-o` и **обязательно берут в экранированные скобки** `\( ... \)`:
```bash
find . -type f \( -iname "*.htm" -o -iname "*.html" \) | wc -l
```
*(Если скобки забыть, флаг `-type f` применится только к первому расширению, и ответ будет неверным!)*

#### 4. Размер файла (`-size`)
В задачах ОГЭ размер всегда даётся в **Кбайтах** ($1\text{ Кбайт} = 1024\text{ байта}$) или **Мбайтах** ($1\text{ Мбайт} = 1024 \times 1024 = 1\,048\,576\text{ байт}$). 

Чтобы не запутаться в округлениях самого Linux, **всегда переводите размер в байты** и ставьте букву **`c`** в конце числа:

* **`+` (строго больше):**
  Найти файлы размером **более 50 Кбайт** ($50 \times 1024 = 51200$ байт):
  ```bash
  find . -type f -size +51200c | wc -l
  ```
* **`-` (строго меньше):**
  Найти файлы размером **менее 10 Кбайт** ($10 \times 1024 = 10240$ байт):
  ```bash
  find . -type f -size -10240c | wc -l
  ```
* **Не менее ($\ge$) и не более ($\le$):**
  В `find` нет нестрогих неравенств, поэтому сдвигаем границу на **1 байт**:
  * **Не менее 10 Кбайт** ($\ge 10240$ байт) $\rightarrow$ строго больше $10239$: `-size +10239c`
  * **Не более 10 Кбайт** ($\le 10240$ байт) $\rightarrow$ строго меньше $10241$: `-size -10241c`
* **Диапазон размеров (логическое «И»):**
  Два флага `-size` подряд работают как логическое «И». Например, файлы **от 10 до 50 Кбайт включительно**:
  ```bash
  find . -type f -size +10239c -size -51201c | wc -l
  ```

#### 5. Исключение папок или файлов (`-not`)
Если в условии сказано: *«посчитайте все файлы в каталоге, **кроме** файлов формата `.pdf`»*:
```bash
find . -type f -not -iname "*.pdf" | wc -l
```
Если сказано: *«посчитайте файлы во всех подкаталогах, **кроме** папки `Поэзия`»*:
```bash
find . -type f -not -path "*/Поэзия/*" | wc -l
```
